# Jewelry Estimator

Internal cost estimating tool for Studio Remod redesign quotes.

Mirrors the existing spreadsheet formula:

Total Cost = Printing + Material + Outside Labor + Internal Design Labor + Internal Logistics Labor

Total Client Price = Total Cost + Stones + Chain + Overhead + Guaranteed Markup + Shipping − Old Gold Refinery Credit (if applicable)

Open `index.html` in a browser to use it.
